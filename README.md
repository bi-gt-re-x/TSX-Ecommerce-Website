# React E-Commerce Website

A modern e-commerce web application built with **React**. The project recreates the core functionality of an online shopping platform using reusable components, state management, and a responsive user interface.

The application focuses on building scalable frontend architecture while providing a smooth shopping experience.

---

## Features

- Browse products
- Dynamic product rendering
- Add and remove items from cart
- Update product quantities
- Shopping cart with live updates
- Responsive design for desktop and mobile
- Component-based architecture
- Client-side routing
- Real-time order summary
- Automatic price calculations
- Tax and shipping calculations
- Persistent cart data

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/react-ecommerce-website.git
```

Navigate into the project:

```bash
cd react-ecommerce-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
